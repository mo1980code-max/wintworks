Overview

Al-Bayan is a complete, professional website for mosques, Islamic centers, schools and charities. It is built with plain HTML5, CSS3 and vanilla JavaScript on top of Bootstrap 5.3.3 — no jQuery, no frameworks, no database, no build tools.

It ships in a single ZIP file. Extract it, and either double-click the offline file to preview instantly, or upload the folder to any hosting and the site is live in minutes.

Quick start

Option A — Preview offline (instant)

1

Extract the ZIP file (right-click → Extract All on Windows, double-click on macOS).

2

Open the al-bayan folder and double-click al-bayan-offline.html.

3

The full styled site opens in your browser — every image, style and script is inside that one file.

Option B — Full site with a local server

1

Open a terminal in the extracted al-bayan folder.

2

Run python -m http.server 8000 (or npx serve al-bayan with Node.js).

3

Open localhost:8000 in your browser and browse every page.

Why plain text appears sometimes: browsers block relative resources when HTML is opened directly from disk. That is a browser security rule, not a bug — use the offline file, a local server, or upload to hosting.

Uploading & installation

Option 1 — Shared hosting / cPanel (most common)

1

Log in to cPanel → File Manager → open public_html.

2

Upload the ZIP file, right-click it and choose Extract.

3

Move the contents of the extracted al-bayan folder into public_html so that public_html/index.html exists.

4

Delete the leftover ZIP and empty folder, then open your domain — the site is live.

5

Optional: set PHP 8.0+ in cPanel so php/contact.php sends real emails.

Option 2 — GitHub Pages (free)

1

Create a free account and a new public repository.

2

Upload the contents of the al-bayan folder (drag files, commit).

3

Settings → Pages → Deploy from a branch → main, folder / (root) → Save.

4

Wait ~1 minute — the site is live on your pages address.

Option 3 — Netlify Drop (fastest)

Create a free Netlify account, open the Drop page, and drag the extracted al-bayan folder onto it. Done — free HTTPS address instantly.

Option 4 — Vercel or Cloudflare Pages (free)

1

Import your repository (or upload directly).

2

Framework preset: Other / None — leave build command and output directory empty.

3

Deploy — live with automatic HTTPS.

Contact form on PHP-less hosts: the form works as a demo without PHP. To send real messages, create a free form on any form service, then in js/main.js POST the form data with fetch() to the endpoint that service gives you. The included php/contact.php documents the exact field names.

Editing & customization

Way 1 — Admin panel (no code, instant)

1

Open admin.html in your browser.

2

Log in with PIN albayan01 (change it in js/admin.js before publishing).

3

Edit hero text, prayer city/method/madhab, courses, events, projects, news, donations and media embeds.

4

Press Save. Edits are stored in that browser/domain; use Reset to restore defaults.

Important: admin edits are per-browser and per-domain. For changes every visitor sees, apply them in data/site-data.js and re-upload that file.

Way 2 — Edit data/site-data.js (permanent)

One readable file holds all content defaults: window.ALBAYAN_DEFAULTS with sections for general, prayer, media, courses, events, projects, news, causes, pricing and contact. Change words between quotes:

general: {
  siteName: "Al-Bayan Islamic Center",
  heroTitle: "A place of learning, worship and giving",
},
prayer: {
  city: "Amman",       // pick from the city list
  method: "MWL",       // MWL | ISNA | Egypt | Makkah | Karachi | Tehran
  madhab: "Shafi",     // Shafi or Hanafi
},

Images, colors & contact email

  • Images: replace files in assets/img/ keeping the same names (hero-1.jpg, about-quran.jpg, event-iftar.jpg ...) — or change the path in data/site-data.js.
  • Colors: edit the CSS variables at the top of css/style.css — one change updates the whole site.
  • Contact email: open php/contact.php and replace the to/from addresses at the top of the file.
  • Arabic/RTL: change <html lang="en" dir="ltr"> to <html lang="ar" dir="rtl"> on every page — the layout flips automatically.

Media embeds & event countdown

Adding YouTube / Vimeo / SoundCloud

Players are rendered from embed URLs in the media section of data/site-data.js — or manage them from the admin panel (Media tab). Replace the placeholders below with the embed address of your own video or track:

media: [
  { title: "Friday Lecture", type: "youtube",
    embedUrl: "YOUR_YOUTUBE_EMBED_URL" },
  { title: "Ramadan Program", type: "vimeo",
    embedUrl: "YOUR_VIMEO_PLAYER_URL" },
  { title: "Quran Recitation", type: "soundcloud",
    embedUrl: "YOUR_SOUNDCLOUD_PLAYER_URL" },
]
  • YouTube: open the video, press Share → Embed, copy the address shown in the embed code (the /embed/... part).
  • Vimeo: open the video, press Share, and copy the player address shown there.
  • SoundCloud: use Share → Embed and copy the player address (the /player/?url=... part).
  • Aspect ratios (16:9, 4:3, SoundCloud) are handled automatically by the CSS classes.

Event countdown

Every event stores an ISO date — the countdown starts automatically on the homepage, events list and event detail page, and stops at zero when the time passes:

events: [
  { id: "ramadan-iftar",
    title: "Community Iftar",
    date: "2026-09-12T18:00:00",   // 'date' drives the countdown
    location: "Main Prayer Hall",
    speaker: { name: "Dr. Ahmad Al-Khatib", role: "Guest Lecturer", bio: "..." },
    schedule: [
      { time: "17:30", title: "Doors open & registration" },
      { time: "18:00", title: "Maghrib prayer & iftar" },
    ] },
]

Troubleshooting

ProblemSolution
Page shows only textBrowsers block relative files from disk. Use al-bayan-offline.html, a local server, or upload to hosting.
Broken imagesKeep the exact structure assets/img/... — Linux hosts are case-sensitive. Re-upload the folder.
Admin edits disappearedEdits are saved per browser/domain. Use the same browser, or make the change permanent in data/site-data.js.
Visitors don't see my editsOnly data/site-data.js changes reach the published site — apply them there and re-upload.
Contact form doesn't sendIt needs PHP hosting. On PHP-less hosts use a form service (see section 6).
Countdown shows zerosThe event date is in the past — set a future date: "YYYY-MM-DDTHH:MM:SS".
Quran audio doesn't playAudio streams from a free CDN and needs internet. If blocked, change the reciter base URLs in data/site-data.js.
