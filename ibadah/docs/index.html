Main site Documentation

1. Folder contents

Download Template (ZIP) — includes all files + this documentation
  • index.html — Homepage (slider, live prayers, causes, courses, pillars, ayat slider, Quran player, projects, media embeds, news)
  • about.html — About Us
  • prayers.html — Prayer times (Hijri date + astronomical calculation)
  • events.html and event.html?id=.. — Events list, schedule table and details
  • courses.html — Courses + pricing plans
  • donate.html — Donation form + campaigns + FAQ
  • contact.html — Contact form + map
  • admin.html — Admin panel (demo code: ibadah01)
  • css/style.css — All styles (incl. media embeds, projects, schedule, speaker bio)
  • js/main.js — Site interactions
  • js/prayer-calc.js — Prayer engine (astronomical)
  • js/admin.js — Admin logic
  • data/site-data.js — Central data file
  • assets/img/ — Images
  • php/ — Optional server examples

2. Run locally

Open index.html directly, or better — run a small server:

python3 -m http.server 8080
# then open: http://localhost:8080

3. Edit texts

The easiest way: open admin.html (code ibadah01), edit and press "Save Changes". Changes are stored in your browser (localStorage) — no server needed.

For permanent file edits: edit data/site-data.js — all site texts, campaigns, courses, events, projects and verses live there as readable JSON objects.

4. Prayer times

  • Astronomical calculation for any coordinates/timezone.
  • Methods: Muslim World League, ISNA, Egypt, Umm al-Qura, Karachi, Tehran, Jeddah.
  • Asr madhab: Standard (Shafi) or Hanafi.
  • Iqamah offsets and Jumu'ah time editable from the admin panel.
  • Hijri dates (Umm al-Qura) automatic via Intl.
  • Qibla direction shown on prayers.html.
  • Print button outputs a clean schedule (CSS Print).

5. Embeddable media

Fully responsive embeds for YouTube, Vimeo and SoundCloud are included on the homepage (#media section) using the .media-embed class (16:9, .tall 4:3, .soundcloud). Replace the iframe src values with your own video/audio URLs.

6. RTL support inside the code

The site is English (LTR) by default, but full RTL support is preserved:

  • CSS uses logical properties (inset-inline-start, etc.) and includes [dir="rtl"] overrides.
  • To switch to Arabic: change <html lang="en" dir="ltr"> to <html lang="ar" dir="rtl"> and swap bootstrap.min.css for bootstrap.rtl.min.css.
  • JS is direction-agnostic — no layout assumptions in code.

7. PHP real connection (optional)

On a PHP host, wire contact.html to php/contact.php and change MAIL_TO. The donation form currently uses a local simulation; connect Stripe/PayPal for real payments.

8. Advanced customization

  • Colors: CSS variables at the top of css/style.css (--green-*, --gold*).
  • Fonts: --font-display and --font-body (Marcellus + DM Sans from Google Fonts).
  • Images: replace files in assets/img/ with the same names, or update paths in data/site-data.js.
  • Validation: all pages are HTML5-valid, responsive on all screen sizes.
