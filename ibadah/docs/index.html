توثيق القالب

الموقع الرئيسي التوثيق

1. محتويات المجلد

  • index.html — الصفحة الرئيسية
  • about.html — من نحن
  • prayers.html — مواقيت الصلاة (تاريخ هجري + اتصال بالحساب الفلكي)
  • events.html و event.html?id=.. — الفعاليات والتفاصيل
  • courses.html — الدورات + خطط الأسعار
  • donate.html — نموذج التبرعات
  • contact.html — اتصل بنا + خريطة
  • admin.html — لوحة إدارة (رمز تجريبي: ibadah01)
  • css/style.css — كل أنماط التصميم
  • js/main.js — تفاعلات الموقع
  • js/prayer-calc.js — محرك المواقيت
  • js/admin.js — منطق لوحة الإدارة
  • data/site-data.js — ملف البيانات المركزي
  • assets/img/ — الصور
  • php/ — أمثلة خادم (اختياري)

2. التشغيل محلياً

افتح index.html مباشرة، أو الأفضل تشغيل خادم بسيط:

python3 -m http.server 8080
# ثم افتح: http://localhost:8080/ibadah/

3. تعديل النصوص

الطريقة الأسهل: افتح admin.html (رمز ibadah01) وعدّل النصوص ثم اضغط «حفظ التعديلات». تخزَّن التغييرات في متصفحك (localStorage) ولا تحتاج أي خادم.

للتعديل الدائم في الملفات: عدّل data/site-data.js — كل نصوص الموقع والحملات والدورات والفعاليات موجودة فيه ككائنات JSON سهلة القراءة.

4. مواقيت الصلاة

  • الحساب فلكي (خوارزمية شمسية) لأي إحداثيات ومنطقة زمنية.
  • مناهج: رابطة العالم الإسلامي، ISNA، مصر، أم القرى، كراتشي، طهران، جدة.
  • مذهب العصر: شافعي/جمهور أو حنفي.
  • فارق الإقامة ووقت الجمعة من لوحة الإدارة.
  • التاريخ الهجري تلقائي (أم القرى) عبر Intl.
  • لاتجاه القبلة يظهر في صفحة prayers.html.
  • زر طباعة الجدول يخرج نسخة نظيفة (CSS Print).

5. ربط PHP حقيقي (اختياري)

على استضافة تدعم PHP، اربط contact.html بالنموذج php/contact.php، وغيّر عنوان MAIL_TO. نموذج التبرع يعمل حالياً بمحاكاة محلية؛ للدفع الحقيقي اربط خدمة مثل Stripe/PayPal وحدّث js/main.js.

6. التخصيص المتقدم

  • الألوان: متغيرات CSS في أعلى css/style.css (--green-*, --gold*).
  • الخطوط: --font-display و --font-body (Amiri + Tajawal من Google Fonts).
  • الصور: استبدل الملفات داخل assets/img/ بنفس الأسماء، أو حدّث المسارات في data/site-data.js.
  • التحقق من الصحة: كل الصفحات HTML5 صالحة ومتجاوبة مع جميع المقاسات.
