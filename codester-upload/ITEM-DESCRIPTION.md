## Full Description

**Al-Bayan** is a professional, multi-page website template built for mosques, Islamic centers, schools and charities. It gives your organization a complete, modern online presence in minutes — everything is pre-built, fully editable, and works without any database or paid service.

The template is written in clean **HTML5, CSS3 and vanilla JavaScript** on top of **Bootstrap 5.3.3**. No jQuery, no frameworks, no build step, no license checks and no activation codes. Just upload the folder to any host and it's live.

### What makes Al-Bayan different

Unlike simple brochure templates, Al-Bayan ships with real, working functionality:

- **Complete Holy Quran** — all 114 surahs (6,236 verses) in Uthmani script with global search, dark reading mode, bookmark, and per-surah streaming audio from **7 reciters**.
- **Live prayer times** — real astronomical calculation for 17 cities, 7 calculation methods, Shafi/Hanafi Asr and iqamah offsets (not static times).
- **Automatic Hijri date** (Umm al-Qura) in the header and prayer strip, plus qibla direction.
- **Event countdown** — live days/hours/minutes/seconds timer to upcoming events, with per-event schedule tables and speaker/researcher bios.
- **Zero-server admin panel** — edit texts, prayer settings, courses, events, projects, news, donations and media embeds from the browser. No database, no backend.
- **Manageable media embeds** — add or remove YouTube, Vimeo and SoundCloud players from the admin panel.
- **Donation module** — campaign cards with goals, raised amounts, progress bars and a donation form.
- **Offline single-file build** — the entire site (including images and the full Quran text) bundled in one file that opens from disk with no internet.
- **10 original images** — created for this item (no stock photos, no watermarks, no EXIF source data).

### Easy customization

1. **Texts, events, media** — via `admin.html` (instant) or `data/site-data.js` (permanent for visitors).
2. **Colors / fonts** — CSS variables at the top of `css/style.css`.
3. **Images** — replace files in `assets/img/` keeping the same names.
4. **Contact email** — set the addresses at the top of `php/contact.php`.

### How to install

1. Extract the ZIP.
2. Open `al-bayan-offline.html` to preview instantly (works offline).
3. Upload the **contents** of the `al-bayan` folder to `public_html` (cPanel/shared hosting), or deploy to any static host (GitHub Pages, Netlify, Vercel, Cloudflare).
4. Open your domain — done.

Full step-by-step hosting guide (5 options) is inside the package documentation.

### Requirements
