## Description

```
Al-Bayan is a professional, multi-page website template for mosques, Islamic centers, schools and charities. Everything is pre-built, fully editable and works without any database, build tools or paid service.

Built with HTML5, CSS3 and vanilla JavaScript on Bootstrap 5.3.3. No jQuery, no frameworks, no license checks, no activation codes, no domain locks. The source code is plain, readable and easy to edit.

- Complete Holy Quran: all 114 surahs (6,236 verses) in Uthmani script with search, dark reading mode, bookmark and per-surah audio with 7 reciters.
- Live prayer times: real astronomical calculation for 17 cities, 7 calculation methods, Shafi/Hanafi Asr and iqamah offsets.
- Automatic Hijri date (Umm al-Qura) plus qibla direction.
- Event countdown with schedule tables and speaker/researcher bios.
- Donation campaigns with goals, progress bars and a donation form.
- Courses with teachers, levels and membership pricing plans.
- Latest projects section and news section.
- Manageable YouTube, Vimeo and SoundCloud embeds from the admin panel.
- Zero-server admin panel: edit texts, prayer settings, courses, events, projects, news and media from the browser (demo PIN: albayan01).
- Mobile-first responsive and print-friendly. RTL-ready: one-line dir="rtl" switch serves Arabic.
- Offline single-file build: the whole site, images and Quran text bundled in one HTML file that opens from disk with no internet.
- 10 original images created for this item (no stock photos, no watermarks, no EXIF source data).
- Validated HTML, CSS and JavaScript (0 errors).

Included files: 11 pages (Home, About, Prayer Times, Quran, Courses, Events, Event Details, Donate, Contact, Admin, plus the offline build), data file for all content, CSS theme variables, admin panel, optional PHP contact endpoint, English documentation (PDF + HTML), credits and license.
```

## Instructions

```
1. Extract the ZIP (right-click > Extract All on Windows, double-click on macOS).
2. Double-click al-bayan-offline.html to preview instantly - no server, no internet.
3. To publish: upload the CONTENTS of the al-bayan folder into public_html (cPanel/shared hosting), or deploy the folder to any static host (GitHub Pages, Netlify, Vercel, Cloudflare).
4. Open your domain - the site is live. No configuration or database needed.
5. Edit content: open admin.html and log in with PIN albayan01 (change it in js/admin.js before going live), or edit data/site-data.js for permanent changes.
6. Replace images in assets/img/ keeping the same file names. Change colors via CSS variables at the top of css/style.css.
7. Set your contact email addresses at the top of php/contact.php.
8. Full illustrated guide (English) is inside docs/ - PDF and HTML versions, no external links.
```
