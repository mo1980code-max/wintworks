## 🚀 النشر على استضافة مجانية (5 دقائق)

### الخيار 1 — GitHub Pages (الأفضل: فيه التحديث اليومي التلقائي)
1. أنشئ حساب على [github.com](https://github.com) (مجاني).
2. أنشئ **مستودع جديد** باسم أي شيء، مثلاً `wintworks`.
3. ارفع كل محتويات مجلد `wintworks` إلى جذر المستودع (سحب وإفلات من متصفح GitHub: **Add file → Upload files**).
4. افتح **Settings → Pages**، ومن **Source** اختر `Deploy from a branch`، الفرع `main`، المجلد `/ (root)` → **Save**.
5. انتظر دقيقتين — موقعك يشتغل على `https://username.github.io/wintworks/` 🎉
6. **التحديث اليومي يعمل تلقائياً**: ملف `.github/workflows/update-jobs.yml` يشغّل سكريبت الجلب كل يوم الساعة 06:23 بتوقيت UTC ويحدّث الوظائف — بدون تدخل منك.

### الخيار 2 — Netlify (أسهل طريقة سحب وإفلات)
1. ادخل [app.netlify.com/drop](https://app.netlify.com/drop).
2. اسحب مجلد `wintworks` كاملاً (أو ملف `WintWorks-site.zip`) وأفلته.
3. انتهيت — الموقع منشور خلال ثوانٍ، والتعبئة الحية تعمل من المتصفح تلقائياً.
4. لا يوجد تجديد يومي تلقائي في Netlify المجاني، لكن **الموقع يملأ نفسه من المتصفح عند كل زيارة**، فلا تحتاجه أصلاً.

### الخيار 3 — Cloudflare Pages
1. حساب على Cloudflare → **Workers & Pages → Create → Pages → Direct Upload**.
2. اسحب مجلد `wintworks` وأفلته → Deploy. نفس فكرة Netlify.

## 🌐 ربط دومينك WintWorks.com

**مع Netlify (الأسهل):** Site settings → Domain management → Add custom domain → اكتب `wintworks.com` → ستعطيك إعدادات DNS:

```
TYPE   NAME          VALUE
A      @             75.2.60.5
CNAME  www           wintworks.netlify.app
```

أضفها في لوحة إدارة الدومين (عند مسجل الدومين أو عند أي مزوّد DNS) وانتظر حتى تنتشر (من دقائق لساعات).

**مع GitHub Pages:** نفس الشيء — Settings → Pages → Custom domain، وأضف سجل `CNAME` يشير لـ `username.github.io`.

> 📌 الدومين يجب أن يكون مملوكاً لك — وهذا موجود عندك مسبقاً.

## 💰 تفعيل Google AdSense (الخطوة اليدوية الوحيدة، وما تحتاجها قبل النشر)

1. افتح [adsense.google.com](https://adsense.google.com) وسجّل بالجيميل، أضف `wintworks.com`.
2. **قبل التقديم انتظر** حتى يتجمع محتوى كافٍ (أسبوعان على الأقل من التشغيل التلقائي يبني +100 وظيفة وصفحات الزحف).
3. بعد الموافقة، انسخ رقمك (مثل `ca-pub-1234567890123456`) والصقه في ملف `js/app.js` في أول الملف هنا:
   ```js
   adsenseClient: "ca-pub-XXXXXXXXXXXXXXXX",   // ← هنا
   ```
   وأنشئ 3 وحدات إعلانية (Display، Responsive) وضع أرقامها في `adSlots`.
4. الأماكن الجاهزة تظهر فوراً: أعلى `#jobs`، بعد كل 12 وظيفة، وصفحة التفاصيل.

### ⚠️ نصيحة صريحة مني لك
- Google يفحص "المحتوى المُجمّع تلقائياً" بدقة، وقد يعترض على مواقع الوظائف المجمّعة إذا كانت نسخاً حرفية فقط.
- **ماذا فعلنا لتقليل الخطر؟**: الواجهة والبحث والفلاتر والحفظ + ترتيب وإعادة تنسيق + أقسام أصلية كاملة (About/Privacy/Terms/Advertise) + ربط دائم بالمصدر الأصلي + «لا نتحقق من الإعلانات» وعدم التظاهر بأنك صاحب الوظائف → كلها ترفع فرص القبول.
- **افعل أيضاً**: أضف مقالتين أصليتين (مثلاً "كيف تكتب سيرة ذاتية أمريكية") بعد نشر الموقع — محتوى أصلي يرفع القبول أضعافاً.
- إذا رُفض الموقع لسبب "المحتوى المجمّع"، الحل الاحتياطي: استخدم **AdSense عبر Creator (YouTube)** أو انتقل لـ Ezoic/Mediavine لاحقاً، أو اعتمد على باقات **Advertise المدفوعة** — وهذا سبب صنعناها لك مسبقاً.

## ❓ أسئلة شائعة

**هل المصادر مدفوعة؟** لا. كلها APIs عامة مجانية بدون مفاتيح، وتعرض بياناتها للجميع وتشترط الإحالة للمصدر الأصلي — متوفر لدينا.

**هل الموقع يغطي أوروبا فعلاً؟** نعم — أعدنا تفعيل Arbeitnow (شبكة وظائف أوروبية) وأضفنا كاشف مدن/دول لأكثر من 100 مدينة أوروبية و50 دولة. حالياً ~270 وظيفة أوروبية + ~176 أمريكية، وتتحدث كل 20 دقيقة.

**هل سأُغرَّم أو مخالف؟** لا. المصادر الأربعة توفّر واجهات عامة صريحة للمطوّرين، ونحن نربط دائماً للصفحة الأصلية ولا ننشر بيانات مستخدمين.

**ماذا لو توقف مصدر؟** الموقع يتجاهل المصدر المتعطل ويكمل بالباقي، ويعرض لك حالة كل مصدر بألوان (أخضر/أحمر) في أعلى القائمة.

**هل أحتاج خادم/قاعدة بيانات؟** لا — موقع ثابت 100% يعمل على أي استضافة مجانية.

**كم يستغرق حتى يظهر إعلاني؟** بعد الموافقة + لصق الكود. مؤقتاً تظهر مربعات "Ad slot" توضح الأماكن الجاهزة.

بالتوفيق يا صديقي 🚀 — وصّلت الدومين، ومن اليوم الموقع يشتغل ويجمع الزيارات بالإيقاع التلقائي.
